# INVERSION LAB — Đảo ngữ nâng cao cho Chuyên Anh

Website học đảo ngữ tiếng Anh từ nền tảng đến nâng cao, được xây dựng bằng HTML, CSS và JavaScript thuần trong một file `index.html`.

## Nội dung
- Công thức nền: trợ động từ, động từ khuyết thiếu và `do/does/did`
- Negative adverbials; Only… / Not until; No sooner… than; Hardly/Scarcely… when
- Not only… but also; đảo ngữ điều kiện với should/were/had
- So… that / Such… that; đảo ngữ chỉ nơi chốn; So/Neither/Nor
- Flashcards tương tác, tìm kiếm cấu trúc, quiz 12 câu và giải thích đáp án
- Thiết kế responsive cho máy tính và điện thoại, hỗ trợ reduced motion

## Chạy tại chỗ
Mở `index.html` bằng trình duyệt hiện đại. Không cần cài thư viện hay build tool.

## Đưa lên GitHub Pages
1. Mở tab **Settings → Pages** của repository.
2. Ở **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn branch `main` và folder `/ (root)`, rồi nhấn **Save**.
4. Sau khi GitHub Pages triển khai xong, link sẽ có dạng:
   `https://ngtrdangquang-pn26.github.io/thuy-t-tr-nh-ti-ng-anh/`
